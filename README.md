# H11V

Кишеньковий воксельний світ для **Waveshare PocketTerm35** — Raspberry Pi 5, екран 3.5″ 640×480 з
тачем і клавіатурою, Sway. Гравець від першої особи ходить невеликим світом, який алгоритм «H11»
повільно переписує сам.

Гра написана **виключно як Lua-моди поверх стокового Luanti**. Рушій не форкався й не патчився: на
пристрої стоїть пакет `luanti 5.10.0` з Debian, на Mac — 5.17 з Homebrew. Усе, що нижче, — це гра,
конфіг і пак текстур.

- [specification/](specification/) — бачення, архітектура, дорожня карта, канон арту
- [docs/decisions.md](docs/decisions.md) — журнал рішень: кожна неочевидна знахідка з поясненням *чому*

## Запуск на Mac

Mac тут — емулятор пристрою, а не друга платформа: те саме вікно 640×480, той самий конфіг. **Частота
кадрів на Mac нічого не означає** — правда вимірюється тільки на пристрої.

```bash
brew install --cask luanti        # якщо ще не стоїть

tools/run_local.sh                # вікно 640×480, профіль mid
tools/run_local.sh --profile=low  # low | mid | high
tools/run_local.sh --fullscreen   # як на пристрої
tools/run_local.sh --fresh        # згенерувати світ наново
```

Скрипт сам робить симлінк гри в теку користувача Luanti і перевіряє, що рушій її бачить. Світи лежать
у `~/Library/Application Support/minetest/worlds/` (так, назва досі дорушієва — це особливість macOS,
скрипт визначає її сам).

## Запуск на пристрої

Створи в корені репозиторію **`.term35-connect.txt`** — він у `.gitignore` і в репозиторій не
потрапляє:

```
ip: 192.168.1.xxx
user: ...
psswd: ...
```

Один раз постав ssh-ключ, щоб далі не питало пароль:

```bash
tools/deploy_to_term35.sh --setup-key
```

Далі:

```bash
tools/deploy_to_term35.sh                 # скопіювати гру + профіль mid і запустити
tools/deploy_to_term35.sh --profile=high  # low | mid | high
tools/deploy_to_term35.sh --fresh         # видалити світ на пристрої
tools/deploy_to_term35.sh --trees=0.004   # рідші рослини (тягне за собою --fresh)
tools/deploy_to_term35.sh --no-run        # тільки скопіювати
tools/deploy_to_term35.sh --stop          # зупинити
tools/deploy_to_term35.sh --log           # дивитись лог гри
```

Деплой ставить і **запис у меню Sway**, тож далі гру можна запускати з `$mod+d` → `H11V`, без
комп'ютера. Запис веде на `run_on_pi.sh`, а не на сам рушій: той скрипт володіє масштабуванням Sway,
змінною `DISPLAY` для XWayland-збірки і створенням світу.

Перевірити, що малює GPU, а не програмний растеризатор:

```bash
tools/gpu_preflight.sh
```

## Керування

### На пристрої

Усі кнопки «джойстика» насправді шлють звичайні клавіші — джойстика в системі немає взагалі, тому це
просто розкладка ([tools/device/gamepad.conf](tools/device/gamepad.conf), додається тільки деплоєм).

| кнопка | дія |
|---|---|
| хрестовина | рух |
| **A** | стрибок |
| **B** | присідання |
| **X** | поставити блок |
| **Y** | копати |
| **L / R** | поворот камери ліворуч / праворуч |
| **Select** | наступний блок у панелі, по колу |
| **Start** | чат |
| **K** | політ увімк./вимк. (далі A — вгору, B — вниз) |
| **H** | noclip — крізь блоки |
| тач | тап — поставити, довге натискання — копати; ведення пальцем — огляд |

Три речі тут варто знати:

- **Повороту камери в Luanti немає як функції.** Огляд — це миша й тач, а миші тут нема. Тому L/R
  зроблені модом [turn.lua](games/h11v/mods/h11_world/turn.lua): кнопки їдуть на контролі `zoom` і
  `aux1` просто тому, що лише їх мод може бачити, а більше ними ніхто не користувався.
- **L дає коротке моргання зуму.** Клієнт передбачає зум у мить натискання, сервер скасовує його
  наступним кроком. Прибрати неможливо — `zoom` не є привілеєм у 5.10, скасовувати нічого. Крок
  сервера піднято до 50 Гц, тож моргання ледь помітне.
- **J нічого не дає.** Це швидкий біг, і привілей `fast` навмисно відкликаний: R несе `aux1`, тож із
  ним гравець розганявся б щоразу під час повороту.

### На Mac

Розкладка джойстика на Mac **не застосовується** — там стандартні клавіші Luanti: `W/A/S/D`, пробіл —
стрибок, Shift — присідання, миша — огляд, ліва кнопка — копати, права — поставити, цифри `1`–`8` —
слоти, `K` — політ, `H` — noclip, `T` — чат, `F5` — налагоджувальний оверлей.

### Чат

`Start` на пристрої, `T` на Mac.

| команда | що робить |
|---|---|
| `/time 6000` | ранок. Аргумент — **тіки, не години**: доба це 0–24000, тож полудень 12000, ніч 23000 |
| `/music on` · `/music off` | фонова музика |
| `/privs` | подивитись власні привілеї |

## Що змінено порівняно зі стоковим Luanti

### Гра — 961 рядок Lua

[games/h11v/mods/h11_world/](games/h11v/mods/h11_world/):

| файл | що робить |
|---|---|
| [nodes.lua](games/h11v/mods/h11_world/nodes.lua) | 13 блоків як **таблиця даних**, у двох половинах: планета (реголіт, фракція, літик, нанос, шпиль, цвіт, тала вода, кора H11) і колонія (обшивка, префаб, ящик, маяк) |
| [mapgen.lua](games/h11v/mods/h11_world/mapgen.lua) | параметри генератора v7, один біом, схема кристалічного шпиля, щільність рослин |
| [player.lua](games/h11v/mods/h11_world/player.lua) | сканер у руці, стартовий інвентар, поява на поверхні, привілеї, хотбар |
| [turn.lua](games/h11v/mods/h11_world/turn.lua) | поворот камери на L/R |
| [music.lua](games/h11v/mods/h11_world/music.lua) | фонова музика по колу |

Блоки, правила й характери ботів живуть **таблицями, а не кодом** — щоб пізніше їх могла
пропонувати модель. Новий блок — це рядок у `NODES`, а не нова гілка в логіці.

Текстур 40, усі з дизайнерського паку ([specification/art/colony/](specification/art/colony/));
процедурної генерації текстур немає. Встановлюються однією командою:

```bash
tools/install_assets.sh            # 32×32, авторський розмір (те, що зараз у грі)
tools/install_assets.sh --res=16   # 16×16
```

Напрямок арту — **колонізація іншої планети**, і це свідома заміна словника v0: трава, земля, кора й
листя — це власний набір матеріалів Minecraft, і перефарбувати його недостатньо. Бриф, правила
розділення кольорів і аудит доставки — у [ART-COLONY.md](specification/ART-COLONY.md).

### Налаштування гри

| ключ | типове | що робить |
|---|---|---|
| `h11v_tree_density` | `0.010` | щільність кристалічних рослин; деплой ставить через `--trees=` |
| `h11v_music` | `true` | фонова музика |
| `h11v_music_gain` | `0.5` | гучність |
| `h11v_button_turn` | `true` | поворот на L/R |
| `h11v_turn_speed` | `2.2` | швидкість повороту, рад/с |

### Профілі графіки

[tools/device/](tools/device/) — спільна база плюс дельта профілю; перемикання профілю це редеплой, а
не правка на пристрої.

| | low | mid | high |
|---|---|---|---|
| дальність огляду | 40 | 60 | 100 |
| шейдери | ні | так | так |
| м'яке освітлення | ні | так | так |
| коливання листя/води | ні | ні | так |
| `fps_max` | 30 | 30 | 60 |

Виміряно на пристрої: low і mid тримають 30 fps при 2–3 мс малювання кадру з бюджету 33 мс. High до
60 не дотягує — рушій сам ріже дальність зі 100 до 60, ганяючись за недосяжною ціллю.

### Ключові рядки базового конфігу

| | |
|---|---|
| `video_driver = opengl` | збірка на пристрої — легаси-Irrlicht під X11, тобто GLX → XWayland → Mesa V3D. Не `ogles2` |
| `touch_controls`, `touch_use_crosshair` | тач без хрестовика не малює прицілу взагалі |
| `hud_scaling 1.4` · `gui_scaling 1.0` · `font_size 14` | панель блоків має лишатись розміром з палець, а діалоги — влазити в 640 px. Це **два різні налаштування**, і плутанина між ними коштувала окремого розслідування |
| `fixed_map_seed` | однаковий світ на Mac і на пристрої |
| `dedicated_server_step = 0.02` | 50 Гц замість 11 — і поворот перестав крокувати, і моргання зуму скоротилось |
| `enable_damage = false`, `creative_mode = true` | v0 про те, щоб ходити, копати й ставити |

### Три місця поза цим репозиторієм

1. **Дві текстури самого рушія підмінені на порожні** — `/usr/share/luanti/textures/base/pack/`,
   екранні кнопки стрибка й присідання, що налазили на панель блоків. Оригінали лежать поруч як
   `.orig`. Це єдине, що взагалі змінено в рушії, і тільки тому, що 5.10 не вміє ці кнопки ані
   прибрати, ані посунути (з'явиться в 5.11). **Зроблено руками — жоден скрипт цього не повторює**,
   тож переустановка пакета `luanti` їх поверне.
2. **Запис у меню Sway** — `~/.local/share/applications/h11v.desktop`, кладе деплой.
3. **Конфіг Sway** — `bindsym Print` перенесено на `$mod+Print`, щоб віддати грі Select. Sway **не
   перечитує конфіг при зміні файлу**, потрібен `swaymsg reload`; резервна копія —
   `~/.config/sway/config.bak-h11v`.

## Перевірки

П'ять воріт приймання, детально — у [specification/ARCHITECTURE.md](specification/ARCHITECTURE.md).

```bash
tools/check_lua.sh        # кожен .lua файл парситься
tools/test_worldgen.sh    # світ генерується headless, і в ньому є те, що має бути
tools/check_assets.py     # пак відповідає канону арту
tools/run_local.sh        # видима перевірка на Mac
tools/deploy_to_term35.sh --profile=mid   # і на пристрої, якщо йдеться про кадри
```

Ніколи не комітимо на червоних воротах.
